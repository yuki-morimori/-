# 🎬 こえオーバーレイ（Live Comment Helper）

配信のコメントを **読み上げ（TTS）** ＆ **画面表示（オーバーレイ）** する、ブラウザだけで動く配信支援ツールのMVPです。

- **GPU不要 / 外部サーバー不要 / 無料** — ブラウザの標準機能だけで動作
- **OBS対応** — オーバーレイをブラウザソースとして取り込めます
- 読み上げは Web Speech API（`speechSynthesis`）、コメント連携は BroadcastChannel を使用

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 管理画面（コメント送信・読み上げ設定・表示設定・プレビュー） |
| `overlay.html` | 表示用オーバーレイ（OBSのブラウザソースに入れる・背景透過） |
| `js/bus.js` | 管理画面↔オーバーレイの連携（BroadcastChannel / localStorageフォールバック） |
| `js/app.js` | 管理画面のロジック（送信・TTS・デモ再生・設定同期） |
| `js/overlay.js` | オーバーレイの表示ロジック |
| `css/style.css` | 管理画面のスタイル |

## 使い方

1. `index.html` をブラウザで開く（管理画面）
2. コメントを入力して送信 → プレビューに表示され、読み上げられます
3. 「▶ デモ自動再生」でサンプルコメントを流して動作確認できます

### OBSで使う

1. OBSで「ソースを追加」→「ブラウザ」
2. URL に `overlay.html` のURLを指定（管理画面の「URLをコピー」が便利）
3. 幅 1920 / 高さ 1080
4. **管理画面を同じブラウザ（同一PC）で開いたまま**コメントを送ると、OBSに反映されます

> コメント連携は同一ブラウザ内で完結します。配信PCのOBS内蔵ブラウザと管理画面を同じPCで開いてください。

## 現状のMVPでできること / 今後の拡張候補

**できること（実装済み）**
- コメントの手動送信・デモ自動再生
- コメント読み上げ（音声・速度・高さ・音量の調整、名前読み上げ）
- オーバーレイ表示（流れる/積み上げ、文字サイズ調整、背景透過）

**今後の拡張候補**
- YouTube Live / Twitch のチャットを自動取り込み（要API連携）
- 棒読みちゃん / VOICEVOX 連携（より自然な音声）
- NGワードフィルタ、コメントの色分け、投げ銭演出
- OBS内蔵ブラウザを別プロセス間で確実に連携する WebSocket サーバー版

## 技術メモ

- 表示テキストは `textContent` で挿入し、コメントによるXSSを防止
- オーバーレイは画面上のコメント数を上限25件に制限（メモリ保護）
- 「流れる」モードのコメントは一定時間後に自動で消える
