# らくらく手配 — 画面ワイヤーフレーム

> [concept.md](./concept.md) の設計をもとにした主要画面のラフ。レイアウト検討用のASCIIモックであり、最終デザインではない。

最終更新: 2026-06-25

凡例: `[ボタン]` / `( )ラジオ` / `[x]チェック` / `▼プルダウン` / `🟦🟩🟧`タグ色 / `🚚`車両 / `★`リーダー / `🚗`運転可

## 0. 画面マップ

```
現場代表者（スマホ）           管理者（PC中心）
─────────────              ──────────────
ログイン(会社ID/コード/PIN)    ログイン(メール+パス)
   └ 本日の確認画面            ├ 配車表エディタ（★中核 §2）
       ├ 残業申請              ├ 当日ダッシュボード（§6）
       └ 回答完了              ├ 承認画面（§7）
                              ├ 記録一覧／集計
                              └ 設定（タグ/取引先テンプレ/車両/従業員）
```

## 8. 設定：タグ管理（ダブルスタンダードの肝）

色だけでも作れる。種別を付けると賢い機能がON。

```
┌────────────────────────────────────────┐
│ タグ管理                         [＋新規] │
├────────────────────────────────────────┤
│ 名前        色    アイコン  種別          │
│ 運転可能    🟦    🚗       能力 ▼        │
│ 新人        🟨    -        区分 ▼        │
│ リーダー     🟦    ★       役割 ▼        │
│ 玉掛け      🟩    🏗       能力 ▼        │
│ 応援        🟧    -        （なし）▼ ←色のみ│
├────────────────────────────────────────┤
│ ※種別「能力」は現場/車両の必要条件と自動照合   │
└────────────────────────────────────────┘
```

## 次の検討（ワイヤーから見えた論点）
- 欠員時に「誰で埋めるか」をこの場で再アサインできると便利（ダッシュボード→エディタ連携）
- リマインドの自動化（未回答が一定時間続いたら自動再通知）
- スマホ版エディタでのドラッグ操作の精度（閲覧専用に割り切る選択肢も）
