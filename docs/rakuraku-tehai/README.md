# らくらく手配

> 配車表を起点に、当日の現場状況をチャットで確認・承認する **「日報レス」現場DXツール** の構想・設計リポジトリ。

紙・Excel・個人LINEで回っている配車と現場報告を、**1日サイクル（配車 → 確認 → 回答 → 承認 → 記録）**で回せるWebアプリにする。
日報文化のない会社（建設・運送・設備・清掃・警備など）が対象。

## コンセプト（一言で）
**「ホワイトボードの"俯瞰できる・みんなで触れる"良さは残し、暗黙ルールはシステムが肩代わりして"誰でも使える"配車表」**

既存のZoomホワイトボード運用は作成者本人しか回せなかった。その「使いこなせない問題」を、
構造化（タグ・必要条件・自動警告）とリアルタイム共同編集で解く。

## 特徴
- 🧩 **3フィールドの配車表エディタ**（人員プール / 車両プール / 現場カードのグリッド）。長押しドラッグで配車。
- 📱 **スマホでも操作可能**（閲覧専用にしない）。PWAでインストール不要。
- 👥 **リアルタイム共同編集**（Zoom WB のように複数人で同時に触れる＋プレゼンス）。
- 🏷 **ユーザー定義タグのダブルスタンダード** … 色だけのやさしい使い方／種別をつけた賢い条件マッチングを両立。
- 🚗 **自動ガード** … 欠員・重複・「車両ありなのに運転手なし」などをアラートパネルで一望。
- 🔑 **やさしい認証**（現場代表者は 会社ID＋従業員コード＋4桁PIN、端末記憶で2回目以降は開くだけ）。
- 🔔 **通知は Web Push 優先**（コストほぼ0）＋ LINE/メールはフォールバック。未回答は自動リマインド。
- 🗂 **マスタは名前だけでも作れる**（しっかり運用もズボラ運用も両対応）。配車入力で自動生成＆二重登録防止。
